# CS50 Readability

This project was completed as part of Harvard CS50x.

## Description
A C program that analyzes a text and calculates its readability grade using the Coleman-Liau Index.

The program counts:
- Letters
- Words
- Sentences

Then it calculates the reading grade level of the text.

## Technologies Used
- C
- CS50 Library
- Math Library

## Concepts Learned
- String analysis
- Loops and conditionals
- Character classification
- Mathematical formulas
- Type casting

## Algorithm Used
Coleman-Liau Readability Index
